# Hero Event Hub

Build a complete, production-quality, cinematic event landing page for a fictional/sample Marvel-inspired tech event organized by the GeeksForGeeks Student Chapter at Bennett University.

PROJECT NAME:
GFG: THE MULTIVERSE PROTOCOL

TAGLINE:
“WHERE HEROES DON'T WEAR CAPES. THEY WRITE CODE.”

IMPORTANT:
This is a design-development task for a student chapter event website. The experience should feel like a premium cinematic Marvel-inspired event website, NOT like a generic college event template.

The primary goal is that when a user opens the website, their first reaction should be:
“Damn, this feels like a Marvel movie opening.”

==================================================
1. CORE EXPERIENCE
==================================================

Create a single-page immersive event experience with strong visual storytelling.

The website should feel:
- cinematic
- premium
- futuristic
- immersive
- dark
- energetic
- interactive
- highly polished
- event-ready

Do NOT make it look like a generic SaaS landing page.
Do NOT use generic template sections with plain cards.
Do NOT make every section look identical.

The website should tell a visual story while the user scrolls.

Scrolling should feel like progressing through a cinematic mission.

==================================================
2. VISUAL IDENTITY
==================================================

Primary color system:
- near-black background: #030504
- dark green: #071A0D
- primary green: #16A34A
- neon energy green: #39FF14
- white/off-white text
- muted grey secondary text

Use green strategically for:
- energy
- highlights
- buttons
- borders
- glow effects
- important labels
- interactive states

Do NOT make the entire website bright green.

The overall visual language should be:
black cinematic environment + emerald/neon green energy + subtle futuristic technology.

Use gradients, glows, particles, atmospheric overlays, depth and lighting carefully.

Maintain excellent contrast and readability.

==================================================
3. TYPOGRAPHY
==================================================

Use a strong modern display font for major headings and a highly readable modern sans-serif for body copy.

Typography should feel:
- cinematic
- futuristic
- premium
- bold

Create clear hierarchy between:
- eyebrow labels
- section headings
- giant display titles
- body copy
- metadata
- CTA text

Avoid excessive font sizes on mobile.

==================================================

- transparent/overlay on hero
- sticky after scrolling
- subtly change background/blur when scrolling
- responsive
- converted into a mobile menu on small screens

Smooth-scroll navigation to sections.

8. HEROES / CHARACTERS SECTION
==================================================

Create a major cinematic section titled:

Use THREE primary Marvel characters:

THE MIND

Each character should have a distinct visual atmosphere.

DOCTOR DOOM:
- dark metallic green
- technological
- strategic
- armored
- powerful
- subtle HUD elements

HULK:
- intense green energy
- huge scale
- impact
- strength
- dramatic lighting
- dynamic composition

LOKI:

- mysterious
- illusion/fog

- subtle distortion

Each character section/card should contain:

role/title
short descriptor
visual artwork
interactive hover state

Character artwork should have layered depth and parallax where appropriate.

IMPORTANT:
Use Marvel-inspired visual treatment and appropriately sourced/stylized assets rather than copying an official Marvel website layout.

==================================================
9. CHARACTER SCROLL TRANSITIONS
==================================================

Make the character section a major part of the scroll experience.

When entering Doctor Doom:
- background becomes darker
- Doom artwork reveals
- text reveals progressively
- metallic green glow appears

Transition from Doom to Hulk:
- Doom atmosphere fades
- green energy expands
- Hulk visual scales into view

Transition from Hulk to Loki:
- energy settles
- atmosphere becomes more mysterious
- fog/glow transitions
- Loki emerges through opacity/blur/parallax

These transitions should feel cinematic but remain smooth and performant.

Do not over-animate everything.

==================================================
16. SCROLL EXPERIENCE
==================================================

This is one of the MOST IMPORTANT requirements.

Scrolling must feel smooth and cinematic.

Implement:
- smooth scrolling
- scroll-triggered reveal animations
- staggered text reveals
- parallax character movement
- scale transitions
- opacity transitions
- blur-to-sharp reveals
- section background transitions
- sticky cinematic elements where appropriate
- subtle progress indicator
- hover interactions

Do NOT make animations excessive.

Every major section should have a deliberate entrance animation.

Animation timing should feel premium and cinematic rather than fast and gimmicky.

Use performant animation techniques.

Respect prefers-reduced-motion.

==================================================
17. MICRO INTERACTIONS
==================================================

Add subtle interactions:
- CTA hover glow
- button magnetic/subtle movement if performant
- card hover lift
- green border illumination
- navigation active state
- character artwork movement
- cursor-following glow only on desktop if performant
- subtle floating particles

Avoid gimmicks that reduce usability.

==================================================
18. RESPONSIVENESS
==================================================

The website MUST be fully responsive.

Test/design for:
- large desktop
- laptop
- tablet
- mobile

Mobile requirements:
- no horizontal overflow
- readable typography
- properly cropped/repositioned character artwork
- touch-friendly buttons
- stacked layouts where needed
- simplified heavy animations if necessary
- mobile navigation
- good spacing
- fast loading
- no broken sections

Do not simply shrink the desktop design.

Design responsive behavior intentionally.

==================================================
19. PERFORMANCE
==================================================

Prioritize smoothness.

Avoid:
- excessive huge assets
- unnecessary 3D
- heavy effects everywhere
- animation loops that hurt performance
- excessive DOM complexity

If a visual effect can be achieved with performant CSS transforms/opacity, prefer that.

Use GPU-friendly animation properties where appropriate.

==================================================
20. TECHNICAL IMPLEMENTATION
==================================================

Use:
- React
- Tailwind CSS
- modern component architecture
- appropriate animation library such as Framer Motion if available
- reusable components
- clean semantic structure

Organize the page into reusable sections/components.

Keep content easy to edit later.

Create a centralized place/configuration for:
- event name
- date
- time
- venue
- registration link
- social links
- event highlights

Do NOT unnecessarily introduce Three.js or heavy 3D unless it genuinely improves the experience without harming performance.

==================================================
21. DESIGN QUALITY
==================================================

The website should look intentionally designed.

Pay close attention to:
- spacing
- typography
- visual hierarchy
- alignment
- section rhythm
- image composition
- contrast
- border radius
- glow intensity
- animation timing
- consistency

Avoid generic AI-generated website patterns.

Avoid:
- excessive rounded cards
- generic gradients
- random colors
- repetitive layouts
- huge amounts of text
- stock SaaS dashboard aesthetics

==================================================
22. IMPORTANT ASSET DIRECTION
==================================================

The characters are an important part of the concept.

Use visually strong, recognizable, stylized/cinematic representations of:
- Doctor Doom
- Hulk
- Loki

Prefer assets that visually match one another.

Do not mix completely different art styles.

If suitable character imagery is not available automatically, create the layout with well-designed image placeholders that can easily be replaced later.

Do not let missing assets break the design.

==================================================
23. IMPLEMENTATION CONSTRAINT
==================================================

Do NOT rebuild or replace working components unnecessarily.

Build the project coherently from the beginning.

Prioritize:
1. complete working website
2. cinematic visual identity
3. scroll experience
4. responsive behavior
5. polish

Do not add unnecessary features outside the event experience.

==================================================
24. FINAL QUALITY BAR
==================================================

Before considering the implementation complete, review the entire page as if you were a frontend/design judge evaluating:

Design Thinking
Creativity
UI/UX
Frontend Execution
Responsiveness
Interactions
Attention to Detail
Overall Experience

The final result should feel like a real premium event campaign website, not a college assignment.

Build the experience around that goal.
